# Glossary, nomenclature and style

## Defined terms

Define each term on first use, in italics. Then use it the same way every time.

| Term | Use it to mean | Do not confuse with |
|---|---|---|
| *Policy–practice decoupling* | Policies are adopted but not implemented (Bromley & Powell, 2012) | Means–ends decoupling |
| *Means–ends decoupling* | Policies are implemented, but the activity is only loosely linked to the stated goals (Bromley & Powell, 2012; Wijen, 2014) | Any gap between plan and outcome |
| *Loose coupling* | A structural property of a system (Weick, 1976; Orton & Weick, 1990) | Decoupling driven by the need for legitimacy |
| *Recoupling* | Practice is brought back into line with stated ends (Hallett, 2010) | Tightening around proxy measures, or re-legitimation |
| *Legacy* | Ex-post structural changes judged against a counterfactual (Preuss) | Leverage; aspiration |
| *Leverage* | An ex-ante strategy with means, owners and timing (Chalip, 2004) | Legacy |
| *Output / outcome / impact* | Anchor these to the OECD-DAC evaluation glossary [C] | Each other |
| *Designed-in (prospective) decoupling* | Decoupling visible in plans and in the means adopted before the event | Realised decoupling of outcomes |
| *Corpus cut-off* | The declared date after which no documents are added | — |
| *Accountability documents* | Audits, budget papers, procurement records, estimates transcripts, RTI releases | "Promise" documents |

- **Hyphenation:** write "means–ends" and "policy–practice" with an en dash.
- **Shortening:** never shorten either term to bare "decoupling" where the distinction matters.

## Vocabulary that signals the wrong paradigm in a Big Q, reflexive design

Flag these and offer the replacements:

| Avoid | Prefer |
|---|---|
| themes emerged | I developed / constructed themes |
| bias (of the researcher) | subjectivity, positionality |
| validated, proved, accurate | supported, warranted, credible |
| saturation | information power, corpus adequacy |
| inter-rater reliability | critical friends, collaborative reflexivity |
| the data show | the documents suggest / construct / indicate |
| percentages of themes | keyness argued qualitatively |
| generalisable | transferable; analytic generalisation |

## Language choices for a governance thesis

- Name the agent in accountability claims: write "GIICA removed the Arena", not "the Arena was removed".
- Hedge interpretive claims about *why* something happened, e.g. "this pattern suggests". Use boosters only for documentary facts.
- Use Hyland's metadiscourse deliberately:
  - frame markers and endophoric markers to signpost;
  - evidentials to attribute sources;
  - self-mention at points of contribution.
- Place given information before new information, and the topic before the stress position (Gopen & Swan).
- Avoid "zombie nouns" (Sword) except for the core constructs.
- Use Australian (Macquarie) spelling, e.g. organisation, programme or program (match the source), analyse.
- Keep the original spelling inside quotations.

## APA 7 patterns (current edition; no 8th edition exists)

The university's thesis format rules override APA's rules for student papers.

- **Headings:**
  - Level 1: centred, bold.
  - Level 2: flush left, bold.
  - Level 3: flush left, bold italic.
  - Levels 4–5: run in to the paragraph.
- **Group authors:** spell the name out at first citation and give the abbreviation, then use the abbreviation. Example: (Queensland Audit Office [QAO], 2024) → (QAO, 2024).
- **Reports:** Group Author. (Year). *Title* (Report No.). URL. Name the most specific responsible agency (UQ Library guide). Example pattern:
  `Queensland Audit Office. (2024). *Preparing for the Brisbane Games* (Report 5: 2024–25). https://www.qao.qld.gov.au/...`
- **Australian legislation:** APA defers to the US Bluebook, so Australian guides adapt the AGLC. UQ uses AGLC3; JCU and UWA use AGLC4. Whether an AGLC 5th edition exists is not confirmed.
  - Reference: *Short Title Year* (Jurisdiction). Example: *Brisbane Olympic and Paralympic Games Arrangements Act 2021* (Qld).
  - In text: *Short Title Year* (Jurisdiction) s 12.
  - Follow the candidate's library guide and apply it consistently.
- **Hansard:** Jurisdiction, *Parliamentary Debates*, Chamber, date, page (speaker). Guides vary, so pick one format and keep to it.
- **Generative AI** (APA guidance, Sep 2025): Company. (Year, Month Day). *Chat title* [Generative AI chat]. Tool. URL of the shared chat.
- **Numbers:** zero to nine in words; 10 and above in numerals, with APA's exceptions.
- **One reference list.** If the documents analysed are listed in a separate corpus appendix, agree this with the supervisor and cross-check the appendix against the reference list.

The illustrative audit-report and IOC templates above are the panel's own patterns. They are not taken from APA or a library guide, so check them against the candidate's library guide.
